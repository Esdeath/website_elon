# 研究档案室设计说明

## 视觉令牌

- 冷白背景：`#F4F6F5`
- 墨色正文：`#141716`
- 白色资料面：`#FFFFFF`
- 发射红：`#C93C2F`
- 信号绿：`#315C4E`
- 冷灰边界：`#D6DCDA`

界面使用 IBM Plex Sans 与中文系统黑体回退；长篇正文使用 Noto Serif SC、宋体回退。字距保持为零，正文控制在约 72 个西文字符的阅读宽度内。

## 布局

```text
桌面首页
┌──────────品牌 / 搜索 / 说明──────────┐
├─时间轴─┬─筛选与排序──────────────────┤
│        ├─资料卡片网格────────────────┤
│        └─分页────────────────────────┘

桌面详情
┌────────────标题与来源────────────────┐
├─媒体与资料栏──────┬─中文 / English───┤
│                   │  长篇正文         │
└───────────────────┴───────────────────┘
```

页面全部左对齐。时间线是真实年代索引，不作为纯装饰；除此以外不添加轨道、星空、光晕等航天套模板元素。缩略图承担真实视觉信息，正文和来源关系保持首要地位。

## 自检结论

最初的“航天控制台”暗色方案过度偏向 SpaceX，也会让访谈和财报长文难读，因此改为明亮的档案阅读界面。设计的识别点集中在红色年代轨和密集但克制的元数据，不使用营销 Hero、嵌套卡片或无意义动效。
